# Transcriptor Fonético del Español

Aplicación de escritorio para transcribir palabras y frases del español
a notación fonética (IPA), pensada como herramienta de práctica para
estudiantes de español.

## Características

- Transcripción a IPA (Alfabeto Fonético Internacional)
- Silabeo ortográfico y fonético
- Encadenamiento fonético entre palabras
- Temas claro y oscuro
- No requiere instalar Python ni dependencias adicionales

## Descarga

👉 **[Descargar la última versión](../../releases/latest)**

Descarga el archivo `.zip`, descomprímelo y ejecuta el instalador.
Instrucciones detalladas dentro del archivo `LEEME.txt` incluido en
la descarga. Al instalar o usar esta aplicación aceptas los términos de EULA.txt.
Las licencias de componentes de terceros están en THIRD_PARTY_LICENSES.txt.
